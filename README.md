# MindCare Health

Premium fictional healthcare landing page for portfolio use.

Layout and interaction patterns follow [Badlands TMS](../../badlands-tms) (floating pill nav, inset hero with layered scrims, alternating sections, soft cards), adapted to the MindCare blue palette with Framer Motion animations.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run

```bash
cd ~/Projects/personal-portfolio/mindcare-health
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

If port 3000 is busy:

```bash
npx next dev -p 3010
```
